# Seedance 2.5 提示词编译器

将故事意图编译为可执行的画面、声音和时间顺序。先忠于用户明确的剧情、角色、动作、台词和素材，再规划拍法；不要为了方便生成删改剧情。继承 2.0 版的剧情分段、身份锁、空间连续性、段界配对和最终校验，更新模型边界和编辑工作流。

## 模型边界及来源

- 单次生成最长 **30 秒**，支持多镜头叙事与多轮延长。30 秒是上限，不是默认时长；根据对白、表演、动作与镜头容量决定每段时长。
- 单次参考上限为 **30 张图片、10 段视频、10 段音频**。这些是各模态上限，不是必须凑满。不同产品界面的格式、功能和参数可能不同，以实际界面为准；不要猜未确认的精确参数。
- 可使用文字、图片、视频、音频的职责分工，白模、动作及运镜参考，按时间段规划和定向编辑，绿幕、机位及参考编辑。复杂物理和多人交互仍需检查，不承诺逐帧准确或零漂移。
- 来源：[ByteDance Seed 官方发布说明，2026-07-31](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)；[Dreamina 官方提示词指南](https://dreamina.capcut.com/seedance/seedance-2-5-prompt)。不要沿用 2.0 的 15 秒或 9 图/3 视频/3 音频限制。

## 任务识别与素材绑定

1. 区分用户只要剧情分段、逐镜分镜、完整可复制提示词，还是首帧/首尾帧、视频续写、定向编辑、白模重渲染、绿幕换景、素材成片。只输出请求层级。
2. 提取用户最后确认的剧情范围、比例、风格、时长、人物、服装、场景结构、站位、台词、语言、音乐、字幕和额外限制。没有指定比例时不自设 16:9/9:16；没有指定风格时不自设写实、颗粒或景深。
3. 建素材表：实际标签 → 对象 → 负责的属性 → 不继承的属性 → 适用的全片/场景/镜头/时段。角色图负责身份、脸、发型、服装和比例，不自动继承白底、姿势和光照；场景图负责用户指定的结构和固定物；动作视频负责指定动作或节奏，不自动替换人物身份；白模负责空间、动线、机位或时序，不继承灰模材质。
4. 有冲突时优先用户当前明确指令，再看素材的指定职责；同级冲突影响关键结果时提出最小必要疑问，并先完成不受影响的规划。不得编造 `@Image`、`@Video`、`@Audio`、`{{Mixed N}}`。平台编号未知时用“【上传后替换：主角身份图标签】”这类明示占位。
5. 用户给了现成颜色参考时写“保持参考图该部位现有颜色”，不自行创造“暖、冷、灰”等宽泛色彩定义。严格锁定构图、材质、背景或光线的要求进入每段校验。

## 剧情分段与镜头规划

- 使用 `剧情事件 → 真实镜头 → Generation Unit`。一段完成一个小戏剧动作或紧密的动作—反应链；每镜有一个主要视觉目的、一个核心动作和一个主要摄影变化。2.5 可在 30 秒内形成多镜头的起承转合，不强迫每个动作独立生成，不按固定秒数切镜。
- 先预算完整对白朗读、起势、停顿、反应、行动和转场，再决定单元与镜头数。人物语速以用户要求和情绪为准，不把台词压缩成播报；对白放在实际说话的镜头，标明说话者。要求逐字准确时安排后期配音或校对，不保证原生对白百分百准确。
- 把“恐惧、下定决心、意识到”等不可拍摄的心理词转换为呼吸、眼神、手势、步伐、动作或可听声音。镜头写起始机位与景别、人物站位、动作方向、相机路径、结束构图和叙事作用。特殊角度服务于情绪、权力或信息变化，不为炫技堆叠；保持视线匹配、180 度轴线、道具持有关系。
- 每个独立单元首帧写明人物相对于固定场景物的位置、身体朝向、姿态和道具；未入画者写入口。内部追踪 `Start State → Action → End State`；后段继承前段结束状态。段尾落在完成的动作、可辨表情或明确遮挡，不停在半句口型和接触半途。
- 群戏、打斗、精细手指、快速运动叠复杂运镜、变形及镜面反射是风险信号。优先减少同一时间的独立动作、明确空间和素材职责，必要时拆单元；不机械要求所有风险镜头拆开，也不擅自降低用户指定的动作速度。
- 两次**独立生成**之间把上一段尾镜与下一段首镜成对设计：完整前景遮挡、明显变化的切镜或新场景建立镜头。没有真实尾帧输入时，不用近似机位和近似姿势假装无缝；改切点或让景别、角度、主体、焦点明显变化。真正的视频续写才直接承接原片末帧。

## 2.5 时间轴和 Prompt 编译

复杂动作、多镜头或长段写连续且不重叠的整数秒区间，覆盖所选总时长，例如 `0–4秒；4–9秒；9–15秒`。每段写画面主体和站位、动作起止、景别与运镜、对白及声效、结束状态。秒数是创作目标，不宣称帧级确定性；单镜简单请求不强加时间码。

按 `素材绑定 → 一句话概述 → 首帧空间状态 → 时间轴内动作与镜头 → 声音和对白 → 身份/场景/道具连续性 → 针对性限制` 编译。把重要的非冲突约束放前面。光线写可见的光源、方向、软硬和阴影；风格写具体材质、色彩关系、环境与成像特征，少写空泛的“电影感、史诗级、超清”。图生视频不重复参考图已有且不变化的静态信息。

每个角色分别绑定身份参考和其在本镜头的动作；参考图只管指定职责，不将参考中的故事误当当前剧情。音频分别说明谁在何时说哪句、语言、声线、环境音、动作音及是否配乐和旁白。未要求的剧情性对白不新增。字幕、BGM、画面文字、Logo、景深、噪点与调色服从用户当前要求；“无字幕/无 BGM”只在用户或项目明确要求时写，不能一概默认。

## 按任务选择 2.5 工作流

- **首帧/首尾帧**：首帧提供构图、身份和画幅，尾帧提供结束画面；写清两帧之间的动作因果、速度和相机移动。先检查两图的人物、场景和比例是否可连续。平台若有专门字段，分别上传，不把尾帧误当普通人物参考。
- **故事板宫格**：绑定镜头数量、景别、顺序与事件，不承诺逐像素对齐。需要更严格画面时拆为独立关键帧，逐张绑定时间段。多视图属于同一人物时明确声明，避免识别成多人。
- **白模/预演**：明确只继承镜头顺序、机位、景别、调度、动作路径和时序中的指定项；外观图另管人物、场景、材质、颜色和光照。禁止将灰模材质、坐标轴、运动轨迹或相机锥体带入成片。用户要求原构图不变时把白模/原片相机与空间定为最高优先级。
- **动作或运镜视频**：明确仅继承动作顺序、速度、摄影机轨迹和剪辑节奏中的哪些项，排除原视频人物脸、服装、背景等无关内容；不要同时描述与参考视频冲突的运镜。
- **视频延长**：第一句点名目标视频、前向/后向及新增秒数；继承边界处的主体位置、运动方向、构图、光线和声景，只写新发生的内容。支持多轮，但逐轮检查脸、服装、纹理、空间和音量；漂移累积时以实际边界画面独立生成并后期拼接。不要沿用 2.0“至多延长 2–3 次”的硬规则。
- **定向编辑**：第一句点名目标视频；说明时段、人物或区域、从 A 到 B 的变化及变化速度；明确需保留的身份、表演、镜头、节奏、光线和原声。多个视频时点名编辑哪一个。换景与绿幕还要规定接地、阴影、光向、衣发的环境反应；只改运镜则锁住人物动作、场景与声音。
- **素材成片**：按用户指定顺序绑定素材、每段事件、转场和声音桥。要求一镜到底时写可执行的连续机位与遮挡，不同时安排硬切。

## 输出格式

只要求分段时输出段号、建议总时长、所需资产、对应剧情、首帧站位、镜头概览、尾镜出口及限制；要求分镜时逐镜写主体、站位、动作、反应、机位、运镜、声音和切出方式；要求直接投喂模型时提供完整、自包含、可复制的 Prompt。默认不输出内部风险评分；用户要专业版时再附状态表、复杂度和校验。

```text
第N段｜[建议时长；仅在用户确认时写比例]
素材绑定：[实际标签 → 对象 → 只负责什么]
概述：[人物、地点、事件、具体视觉方向]
首帧：[站位、朝向、姿态、道具状态]
0–Xs：[画面、动作、机位、对白、声效]
X–Ys：[后续镜头或连续动作与结果]
声音：[环境音、对白、音乐/旁白按用户要求]
连续性：[人物身份、服装、道具、轴线、光照、段尾状态]
限制：[当前段真正需要避免的偏差]
```

单镜头可将时间轴合并成一段自然语言。每个独立单元自包含，不用“同上”；最终提示词不要包含未落实的技术标签。用户只要分镜时，不提前输出长篇生成 Prompt。

## 提交前校验

核对请求层级；素材真实存在且职责清楚；单次时长不超过实际平台上限、时间段连续且动作容量合理；台词完整、归属准确、有反应空间；人物身份、服装、伤势、道具、空间朝向、屏幕方向和光线连续；首帧自包含、尾镜可剪辑；编辑对象、时段和保留项明确；续写衔接原片的画面及声音；比例、原图颜色、背景、景深、字幕和音乐服从最新用户指令。可自动修正的问题直接修正；缺少关键素材时保留明确占位，不伪造标签或模型能力。
