# 独立生成段的段界设计

## 目录

1. 核心判断

## 1. 核心判断

每个 Generation Unit 都由独立提示词和场景参考图生成。相邻段即使描述相似，也会在人脸、姿态、服装褶皱、背景结构、光线和摄影机位置上产生细微变化。因此：

- 不把两个独立生成段设计成同一个长镜头的直接延续，除非下一段实际使用上一段最后一帧续写。
- 相邻段越像同一构图，细微差异越容易被观众识别为跳帧。
- 段界设计的目标不是让两帧相似，而是让剪辑发生得合理、差异有动机。
- 每个段界必须同时设计上一段尾镜和下一段首镜，不能分别孤立编写。

## 2. 首选策略

按可靠性优先选择：

1. **完整遮挡后揭示**：最适合在同一地点延伸空间、切换场景参考图或重新建立人物站位。
2. **显著差异化切镜**：最适合对话反应、信息揭示、动作结果和景别变化。
3. **新场景建立镜头**：适合地点或时间变化，让观众明确接受视觉重置。
4. **中性插入镜头**：道具、手部、脚步、门、账册等能够承载叙事的细节。
5. **真实尾帧续写**：仅在工作流确实把上一段最后一帧作为下一段参考输入时使用。

优先选择简单、稳定的策略，不为炫技增加模型难度。

## 3. 遮挡转场规范

适用情形：角色横向行走、摄影机横移、经过门柱、树干、帷幔、墙角、近景人物或大型家具；需要换用同地点的新场景图。

上段尾镜：

- 人物或摄影机保持明确的单一运动方向。
- 前景障碍逐渐进入画面，最终覆盖全部或绝大部分画面。
- 在遮挡充分覆盖、背景已不可辨认时结束。
- 不在只遮住一小部分画面时切断，否则下一段新背景会直接跳变。

下段首镜：

- 从同类颜色、材质或亮度的近距离遮挡开始。
- 遮挡的退出方向要延续上段运动趋势。
- 遮挡移开后才揭示新的场景参考图、机位或人物站位。
- 人物行进的屏幕方向保持一致；例如上段从左向右移动，下段揭示后仍向右延伸。

遮挡物不必像素级相同，但需要在色调、运动方向和覆盖程度上合理。深色柱体切深色树干、红色帷幔切红色门帘可以成立；半透明窗纱切实木柱通常不成立。

## 4. 差异化切镜规范

当无法精确延续画面时，主动让观众感知这是一次正常切镜。下段首镜相对上段尾镜，至少在以下六项中的两项明显不同：

- 景别：特写切全景、近景切中远景。
- 角度：侧面切正面、平视切明确俯拍或仰拍。
- 主体：说话者切听者、人物切关键道具。
- 构图：单人切双人、过肩切干净单人、纵深切平面构图。
- 焦点：人物脸切前景物件或背景反应。
- 运动状态：静止镜头切明确跟拍，或运动完成后切固定反应镜头。

差异化不代表破坏连续性。必须继续满足：

- 动作因果一致。
- 人物屏幕方向与视线匹配。
- 道具仍在正确位置。
- 时间、光线、服装和伤势连续。

可靠示例：

- 上段尾镜停在裴铮近景说完关键句；下段首镜切皇帝高台侧面的中远景，展示皇帝和二皇子的反应。
- 上段尾镜是人物转头看向画外；下段首镜是他所看见的对象或空间全景。
- 上段尾镜是账册落地特写；下段首镜切二皇子俯视账册的中景。

## 5. 其他可靠方法

- **人物出画再入画**：上段让人物完全离开画面，下段用明显不同机位拍他进入新的构图。
- **门的开合**：上段以门关闭或门板遮满画面结束，下段从门开启或门后新空间开始。
- **反应切换**：上段结束说话者完整台词，下段从听者的明确反应开始。
- **道具插入**：利用叙事重要道具连接前后，但道具造型和持有状态必须锁定。
- **声音桥**：下一段声音提前进入或上段声音延续，帮助观众接受画面变化；声音桥不能单独掩盖近似画面的跳动。
- **快速摇镜或运动模糊**：上段以单方向运动模糊结束，下段从同方向模糊中稳定下来。此法模型风险较高，只在运动明确且无更稳定方案时使用。

## 6. 高风险方法

默认禁止：

- 上段和下段都是同一人物、同一景别、同一机位，只把动作描述改了一点。
- 上段尾镜停在人物微表情，下段首镜要求保持完全相同表情继续说话。
- 上段尾镜正在拥抱、递物、打斗或拉扯，下段首镜从动作半途继续。
- 上段局部遮挡，但下段已经换了背景结构或场景参考图。
- 只用“保持上一段一致”“无缝衔接”代替可执行的首尾画面。

如果剧情必须保持相同机位连续表演：

1. 尽量合并到同一个 Generation Unit；或
2. 明确要求使用上一段真实尾帧作为下一段首帧参考；或
3. 在动作前后增加遮挡、反应或道具插入镜头，重新设计段界。

## 7. 段界配对模板

规划相邻段时内部使用：

```text
段界策略：完整遮挡 / 差异化切镜 / 新场景建立 / 中性插入 / 真实尾帧续写
上段尾镜：主体、运动方向、最终构图、可剪辑出口。
下段首镜：初始构图、与尾镜的差异或遮挡延续、揭示后的主体和站位。
连续要素：屏幕方向、视线、动作结果、道具、光线、声音。
禁止风险：本段界最容易发生的跳帧或错位。
```

最终分段输出不展示“段界策略”“禁止风险”“首镜入口”等内部字段。段界设计必须直接落实到上一段的“尾镜出口”和下一段的“镜头1”；下一段在镜头1之前另写完整“初始人物站位”，保证其脱离前段也能独立生成。
