## 1. 输出层级

### 分段模式

用于“生成分段”。按纯正文输出建议总时长、所需资产、对应剧情、初始人物站位、逐镜头画面、尾镜出口和完整限制。对白直接写进发生该对白的镜头。不要提前堆入无关风格词和内部技术标签。

### 分镜模式

用于“生成分镜”。每镜写清主体、站位、动作、反应、机位、景别、运镜、声音和切出方式。只标段落总时长，除非用户明确要求逐镜时长。

### 最终提示词模式

用于“生成第N段”“给可生成视频提示词”。每段必须自包含，不依赖“同上”。

## 2. 最终单元结构

按下列顺序组织，字段可自然成文，但信息不能缺失：

1. 段号与建议总时长。
2. 所需资产：人物资产、场景资产、道具资产，确有需要时增加音频资产。
3. 对应剧情。
4. 初始人物站位：第一帧人物位置、相对关系、身体朝向、视线、姿态和关键道具状态；稍后入场者写明尚未入画及入口。
5. 逐镜头画面：统一用“镜头1：”“镜头2：”，写清主体、站位、动作、反应、机位高度、角度、景别、运镜、对白和切镜。
6. 尾镜出口与段落结束状态。
7. 针对本段的完整硬性限制。

比例只在当前项目明确时写。不要输出“首镜入口”、独立人物朝向栏、对白清单、内部策略名、风险评分、Start State/End State 英文标签或模型路由判断，除非用户明确要求技术版。

使用纯正文，不使用 Markdown 加粗或 `1.`、`2.`、`3.` 自动编号。每段资产、初始人物站位和限制都完整重写，不使用“同上”。

## 3. 资产引用

- 只使用真实存在的引用标签。
- 没有实际映射时写：`【插入：资产名称的实际引用标签】`。
- 人物图锁定身份，不锁死姿势和资产图光线。
- 场景图锁定结构与固定材质，不强迫复制参考图的摄影机位置。
- 道具图锁定造型、材质和尺度。
- 视频参考只控制明确要求的动作、节奏或运镜，不复制无关人物和背景。

## 4. 限制写法

限制应具体、可检查，并针对本段风险：

- 身份：人物脸、发型、服装、年龄和身高关系一致。
- 空间：门窗、楼梯、柜台、家具、道路和人物站位连续。
- 动作：不瞬移、不重复动作、不跳过接触过程、不多肢体。
- 道具：不凭空出现、消失或换手。
- 对白：不新增、不删减，角色归属和中文口型准确。
- 风格：不混入用户未要求的动漫、解说漫、仙侠或现代元素。
- 画面：无水印、无多余字幕；BGM与字幕按用户要求，不默认写死。

不要把通用负面词无限复制。每段先写最容易出错的限制。

用户未另行要求时，限制基线写为：无字幕、无文字贴纸、无水印、无BGM、无旁白、无新增对白；说话人物准确同步中文口型，未说话人物保持闭口；人物脸型、发型、服装及剧情要求的关键造型连续一致。随后追加本段最容易出错的空间、动作、道具和身份限制。

## 5. 最终校验

输出前逐项确认：

- 剧情范围没有越集或漏台词。
- 建议时长足以完成对白、动作、反应和转场。
- 每镜只有一个核心动作和一个主运镜轴。
- 整场镜头不是全部平视中景；情绪、权力或主观视角变化处已评估合适的特殊角度。
- 虫视、POV、俯拍、仰拍、顶视或极近特写均写明视角归属、空间关系和叙事目的。
- 特殊角度没有连续堆叠，且其前后有清晰的空间或反应镜头托底。
- 高级运镜已翻译为明确的摄影机路径、镜头焦距或速度变化、主体动作和结束构图，没有只写技法名称。
- 希区柯克变焦、英雄环绕、甩镜、升降揭示、长镜头等只用于匹配的叙事节点，并符合AI稳定性限制。
- 所有人物站位、视线和屏幕方向可从画面推导。
- 每段镜头1之前已写完整初始人物站位，且与镜头1一致。
- 上一段结束状态与本段开场一致。
- 上一段尾镜和本段首镜形成明确的剪辑对，不是近似构图的伪连续。
- 没有真实尾帧输入时，没有要求模型从几乎相同的画面精确续拍。
- 参考图职责不冲突，未编造引用。
- 当前未明确视频比例时，输出没有比例。
- 用户只要求分段时，没有误输出整套最终 Prompt。
